# Security Policy

## Reporting a Vulnerability

Report security issues privately via GitHub's **Private vulnerability reporting**
on this repository: navigate to the **Security** tab and click **Report a vulnerability**.
This is the sole reporting channel; a direct email channel may be added in a future
update.

Do not file public issues for vulnerabilities. Public disclosure before a fix is
available puts users at risk.

## Supported Versions

Only the latest published image tag is supported. Pin to a specific version in
production and upgrade deliberately after reviewing release notes.
